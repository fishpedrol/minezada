Os testes que não dependem do Minecraft passam; o build Forge e os GameTests ainda precisam rodar numa rede com acesso ao maven do Forge e da Mojang (veja [TODO.md](TODO.md) e [NEXT_SESSION.md](NEXT_SESSION.md)).
